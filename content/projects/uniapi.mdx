UniAPI 起源于一个很朴素的需求：让项目需要的常用能力拥有统一、清晰并且足够可靠的接口。

基础 API 无需注册即可直接调用，文档尽量让每一个输入和返回值都不需要猜测。因为真实项目持续依赖它，稳定性、可扩展性与快速迭代从来不是宣传语，而是每天都要兑现的约束。

## 把基础工作做好

UniAPI 由文档站、管理控制台与后端服务共同组成。新的 Go 服务采用面向大型项目的分层结构，从配置、日志、领域模型到 HTTP transport 都保留了清楚的边界。

它不追求用复杂性证明技术能力，只希望让“调用一个工具”重新变成一件足够简单的事。
